# OpenLinkHub Nexus 0.9.8N

**OpenLinkHub Nexus 0.9.8N** is a maintenance release of the independently maintained OpenLinkHub Nexus fork, following `0.9.7N`. This release includes the changes merged to `main` after `0.9.7N`. It is not an official Corsair, Elgato, or upstream OpenLinkHub release.

## Changes since 0.9.7N

### Deck HID connection stability

- Fix handling of interrupted Deck HID reads so an interrupted read is not incorrectly treated as a device disconnection.
- Keep existing Deck page/layout behavior and reconnect handling intact.
- Adds regression tests for interrupted HID reads.

### Desktop agent installation guidance

- After installing the native package, display opt-in setup instructions for the separately running logged-in desktop agent.
- Update the desktop launch documentation to make setup clearer. The agent is used for local desktop actions and experimental Deck plugin hosting, and is not automatically enabled without user action.

### Existing functionality

- Retains `0.9.7N` improvements, including experimental classic Elgato Stream Deck support, experimental Deck action plugins, Stream Deck icon-pack imports, improved Mirabox/Nexus editors, and upstream device/telemetry updates.
- Elgato hardware and the plugin system remain **experimental**; hardware and third-party plugin compatibility vary.

## Download and installation (Linux amd64)

All formats are built from one versioned release executable, and each has its own SHA-256 checksum file.

| Format | Asset |
| --- | --- |
| Debian / Ubuntu / Linux Mint | `OpenLinkHub-Nexus_0.9.8N_amd64.deb` |
| Fedora-compatible RPM | `OpenLinkHub-Nexus-0.9.8N-1.x86_64.rpm` |
| Portable Linux amd64 | `OpenLinkHub-Nexus-0.9.8N-linux-amd64.tar.gz` |

**Release downloads:** https://github.com/avonderau/OpenLinkHub-Nexus/releases/tag/0.9.8N

Download the matching `.sha256` file and verify the package before installation. On Linux Mint or Ubuntu:

```bash
sha256sum -c OpenLinkHub-Nexus_0.9.8N_amd64.deb.sha256
sudo apt install ./OpenLinkHub-Nexus_0.9.8N_amd64.deb
```

The native packages require Linux x86-64 with glibc 2.38 or newer and their declared system dependencies. Preserve your configuration, profiles, icons and layouts when upgrading, and stop any separately launched test executable before starting the installed service.

## Validation and caveats

- The release workflow verifies the relevant Go and browser tests, builds the portable executable, creates DEB/RPM packages from that bundle, and verifies matching package contents and checksums.
- The desktop agent runs in the user's graphical session and is opt-in. Read [desktop agent setup](https://github.com/avonderau/OpenLinkHub-Nexus/blob/main/docs/nexus-desktop-launch.md) before enabling application-launch or plugin actions.
- For the experimental plugin host, install only trusted plugins: they execute code with the desktop user's permissions.
