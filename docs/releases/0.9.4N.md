# OpenLinkHub Nexus 0.9.4N

**First OpenLinkHub Nexus fork release**, based on upstream OpenLinkHub **0.9.4**.

The `N` suffix identifies this independently maintained Nexus-enhanced fork. It is not an upstream OpenLinkHub release.

## Highlights

- Programmable Corsair iCUE NEXUS 640×48 screens, metrics and graphs, content widgets, touch buttons and saved layouts.
- Five-tab editor with compact charcoal-and-amber property inspector, library, backgrounds, layout imports/exports and application-triggered screens.
- GIF image/background support, typography, icon and widget appearance controls.
- Bounded, validated hotkey/media/mouse/text actions and integration with saved macros.
- Host-local Open URL and application launch support via a separate opt-in non-root desktop helper for background services.
- Recent upstream main synchronization and regression tests for Nexus, UI and merge compatibility.
- **Patched Go toolchain:** Go 1.26.10 replaces vulnerable Go 1.26.0 for the release, CI and Docker builds.
- **Security hardening:** daemon-owned launcher socket and Linux peer verification, stricter Nexus API origin and upload checks, safer installer permissions, CodeQL coverage expanded to JavaScript and added race/vulnerability scanning.
- GitHub links and remote installer use this fork's repository rather than upstream.

## Linux amd64 bundle

Download the `OpenLinkHub-Nexus-0.9.4N-linux-amd64.tar.gz` asset and verify its SHA-256 digest against the matching `.sha256` file before installation. This source-built bundle includes the application binary, static assets, templates and supporting files. It is not a .deb or .rpm package.

Read [the fork README](https://github.com/avonderau/OpenLinkHub#installation-of-this-fork) and [desktop agent instructions](https://github.com/avonderau/OpenLinkHub/blob/main/docs/nexus-desktop-launch.md).

**Important:** Nexus URL/App touch buttons open applications on the **host's graphical desktop**, not in a remote browser tab. If OpenLinkHub runs as a system service, start the opt-in local desktop helper as the logged-in user.

## Security and compatibility

Read the [0.9.4N security work-up](https://github.com/avonderau/OpenLinkHub/blob/main/docs/security-review-0.9.4N.md) before exposing the WebUI beyond localhost. Authentication is optional in upstream OpenLinkHub; do not expose an unauthenticated instance to untrusted networks.

Nexus hardware behavior and all distributions have **not** been validated on physical devices as part of this release. Upstream OpenLinkHub remains separately maintained by [Nikola Jurkovic](https://github.com/jurkovic-nikola/OpenLinkHub).
