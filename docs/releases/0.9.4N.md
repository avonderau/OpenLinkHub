# OpenLinkHub Nexus 0.9.4N

**First OpenLinkHub Nexus fork release**, based on upstream OpenLinkHub **0.9.4**.

The `N` suffix identifies this independently maintained Nexus-enhanced fork. It is not an upstream OpenLinkHub release.

## Highlights

- Programmable Corsair iCUE NEXUS 640×48 screens, metrics and graphs, content widgets, touch buttons and saved layouts.
- Five-tab editor with compact charcoal-and-amber property inspector, library, backgrounds, layout imports/exports and application-triggered screens.
- GIF image/background support, typography, icon and widget appearance controls.
- Bounded, validated hotkey/media/mouse/text actions and integration with saved macros.
- Host-local Open URL and application launch support via a separate opt-in non-root desktop helper for background services.
- Recent upstream main synchronization and regression tests for Nexus, UI and merge compatibility.
- **Patched Go toolchain:** Go 1.26.10 replaces vulnerable Go 1.26.0 for the release, CI and Docker builds.
- **Security hardening:** daemon-owned launcher socket and Linux peer verification, stricter Nexus API origin and upload checks, safer installer permissions, CodeQL coverage expanded to JavaScript and added race/vulnerability scanning.
- GitHub links and remote installer use this fork's repository rather than upstream.

## Linux amd64 downloads

This release offers **three distribution options**, all containing the **same 0.9.4N executable**:

| Format | File | Intended use |
| --- | --- | --- |
| Modern Debian/Ubuntu/Mint | `OpenLinkHub-Nexus_0.9.4N_amd64.deb` | Native system service package: `sudo apt install ./OpenLinkHub-Nexus_0.9.4N_amd64.deb` |
| Fedora-compatible distros | `OpenLinkHub-Nexus-0.9.4N-1.x86_64.rpm` | Native system service package: `sudo dnf install ./OpenLinkHub-Nexus-0.9.4N-1.x86_64.rpm` |
| Generic Linux amd64 | `OpenLinkHub-Nexus-0.9.4N-linux-amd64.tar.gz` | Existing portable bundle/user-space installation; no package manager integration |

Download from [this fork's release page](https://github.com/avonderau/OpenLinkHub-Nexus/releases/tag/0.9.4N). Verify each download using its matching `.sha256` file with `sha256sum -c <filename>.sha256`.

**Compatibility:** These packages wrap the existing Linux amd64 release executable, which requires **glibc 2.38 or newer**. This excludes, for example, Debian 12 and RHEL 9. Use a distro with a compatible libc and device libraries. RPM's auto-generated ELF dependencies and DEB's libc dependency enforce this requirement. 

**Package behavior:** The DEB/RPM installs the systemd service at `/usr/lib/systemd/system/OpenLinkHub.service` and a udev rule. It creates the `openlinkhub` service account if needed, keeps the packaged executable and WebUI files root-owned, and makes only database/configuration and Nexus runtime folders writable by the service. Existing `/opt/OpenLinkHub/config.json` is retained on upgrades. Manual or user-service installations may already use the same service name or directory: back up your configurations, stop the old service, and remove conflicting upstream packages/service units before switching to a system package. These packages are **not** suitable for immutable distributions that disallow traditional DEB/RPM installation.

The portable tarball is still available and unchanged; all three formats contain the same original release executable. Package lifecycle behavior has been checked in CI but has not yet been validated across every supported distribution or on physical Nexus hardware.

Read [the fork README](https://github.com/avonderau/OpenLinkHub-Nexus#installation-of-this-fork) and [desktop agent instructions](https://github.com/avonderau/OpenLinkHub-Nexus/blob/main/docs/nexus-desktop-launch.md).

**Important:** Nexus URL/App touch buttons open applications on the **host's graphical desktop**, not in a remote browser tab. If OpenLinkHub runs as a system service, start the opt-in local desktop helper as the logged-in user.

## Security and compatibility

Read the [0.9.4N security work-up](https://github.com/avonderau/OpenLinkHub-Nexus/blob/main/docs/security-review-0.9.4N.md) before exposing the WebUI beyond localhost. Authentication is optional in upstream OpenLinkHub; do not expose an unauthenticated instance to untrusted networks.

Nexus hardware behavior and all distributions have **not** been validated on physical devices as part of this release. Upstream OpenLinkHub remains separately maintained by [Nikola Jurkovic](https://github.com/jurkovic-nikola/OpenLinkHub).
