# OpenLinkHub Nexus 0.9.7N

**OpenLinkHub Nexus 0.9.7N** follows `0.9.6N` and contains the changes merged into `main` since that release. This is an independently maintained fork, not an official Corsair, Elgato, or upstream OpenLinkHub release.

## Highlights

### Experimental native Elgato Stream Deck support

- Added a native HID driver for supported classic Elgato Stream Deck models, including Original, Original V2, Mini, Mini Mk.2, MK.2 and XL variants.
- Support for key presses, LCD key image transfer, and brightness where supported by the device's protocol.
- **Experimental, not physically validated on Elgato hardware.** This is separate from the previously released Stream Deck icon-pack import feature. Stream Deck Neo, Plus and other touch-strip/dial models are not supported.

### Experimental Deck action plugins

- Added an experimental user-session plugin host for compatible **Elgato Stream Deck SDK** and **OpenAction** action plugins with supported Linux runtimes.
- New **Plugins** tab in the Deck editor for installation and management of compatible `.streamDeckPlugin` or `.zip` packages.
- Added plugin settings/property-inspector pages in the Deck editor, plugin titles and key images, key-down/key-up events when hardware supports release events, and supported settings messages.
- Plugin execution is isolated from the OpenLinkHub system service: the existing logged-in desktop agent launches plugin processes under the desktop user, with a local-only authenticated WebSocket channel and a desktop confirmation before installing executable plugin code.
- Plugins are **user-supplied executable code**. Install only trusted plugins. The host and supported SDK subset are experimental; Windows/macOS-only plugins, Marketplace DRM plugins, hardware plugins, dials and multi-actions are not supported. See [Deck plugin documentation](https://github.com/avonderau/OpenLinkHub-Nexus/blob/main/docs/deck-plugins.md).
- The plugin installer requires a graphical confirmation utility (`zenity` or `kdialog`). JavaScript-based plugins additionally require a compatible Node.js runtime.

### Upstream hardware and telemetry updates

- Incorporated newer upstream OpenLinkHub changes, including configurable LED count and an Off lighting mode for lnpro hardware.
- Preserved temperature smoothing state across frames and accepted decimal NVIDIA GPU temperature reports.
- Integrated the upstream changes while retaining the fork's Nexus, Mirabox, icon-pack and Deck enhancements.

## Download and installation (Linux amd64)

This release publishes a portable archive, native Debian package and RPM from one versioned executable, with individual SHA-256 checksum files.

| Format | Asset |
| --- | --- |
| Debian / Ubuntu / Linux Mint | `OpenLinkHub-Nexus_0.9.7N_amd64.deb` |
| RPM | `OpenLinkHub-Nexus-0.9.7N-1.x86_64.rpm` |
| Portable Linux amd64 | `OpenLinkHub-Nexus-0.9.7N-linux-amd64.tar.gz` |

**Release downloads:** https://github.com/avonderau/OpenLinkHub-Nexus/releases/tag/0.9.7N

Download the corresponding `.sha256` file and verify the archive before installing. For Linux Mint and Ubuntu:

```bash
sha256sum -c OpenLinkHub-Nexus_0.9.7N_amd64.deb.sha256
sudo apt install ./OpenLinkHub-Nexus_0.9.7N_amd64.deb
```

Native packages require Linux x86-64, glibc 2.38 or later, and the declared system dependencies. Before upgrading, preserve important configuration, macros, icon packs and custom Nexus/Deck layouts, and do not run a separate test instance while the installed service controls the same USB devices.

## Quality and known limitations

- Changes were merged with automated Go and editor UI tests and upstream compatibility verification; the release workflow additionally validates sources, builds, and checks the release packages.
- Experimental Elgato hardware and plugin compatibility remain dependent on real-device/runtime testing. Plugin availability varies with the plugin's manifest, platform-specific executable and installed dependencies.
- For security, only install plugins from sources you trust; downloaded plugins execute in your desktop session with your user's permissions.
- Existing Mirabox devices, Nexus layouts, icon packs and saved Deck profiles remain supported.
